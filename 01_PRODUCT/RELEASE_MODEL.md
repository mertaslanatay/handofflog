# Release ve Değişiklik Modeli

## Release türleri

- Patch
- Minor
- Major
- Hotfix
- Content Update
- Design System Update

## Etki seviyeleri

### Low
Metin düzeltmesi, küçük görsel ayar veya geliştirici aksiyonu gerektirmeyen değişiklik.

### Medium
Kod veya layout güncellemesi gerektiren spacing, typography, state veya component değişikliği.

### High
Akış, navigation, ortak component veya birden fazla platformu etkileyen değişiklik.

### Breaking
Mevcut implementasyonu geçersiz kılan silme, rename, property yapısı veya akış değişikliği.
