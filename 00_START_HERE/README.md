# Handofflog — Cowork Workspace

Handofflog, handoff sonrasında Figma tasarımlarında yapılan değişiklikleri yakalayan, anlamlandıran ve geliştiricilere release/changelog olarak ileten bir Figma plugin + web dashboard ürünüdür.

## Cowork ile başlama

1. Bu klasörü bilgisayarına çıkar.
2. Claude Desktop > Cowork üzerinden bu klasöre erişim ver.
3. İlk olarak `00_START_HERE/COWORK_MASTER_PROMPT.md` dosyasını açtır.
4. Cowork'tan `05_COWORK_TASKS/PHASE_01_TECHNICAL_PROTOTYPE.md` görevini uygulamasını iste.
5. Her önemli kararı `06_REFERENCE/DECISION_LOG.md` içine yazdır.
6. Tamamlanan işleri `04_DELIVERY/IMPLEMENTATION_BACKLOG.md` içinde güncellet.

## Kaynak önceliği

1. `00_START_HERE/COWORK_MASTER_PROMPT.md`
2. `01_PRODUCT/PRD.md`
3. `03_TECHNICAL/TECHNICAL_ARCHITECTURE.md`
4. İlgili faz görev dosyası
5. Backlog ve kabul kriterleri

## Temel ürün döngüsü

Select → Snapshot → Change → Scan → Review → Publish → Acknowledge
